# 🏥 Hospital Patient & Revenue Analysis Using Excel

## 📌 Project Overview
This project focuses on analyzing hospital patient and revenue data using Microsoft Excel. The objective is to transform raw healthcare data into meaningful insights through data cleaning, exploratory analysis, and interactive dashboard development.

## 🎯 Objectives
- Improve data quality by cleaning and transforming raw hospital data.
- Analyze patient demographics, billing amounts, revenue trends, and patient ratings.
- Build an interactive dashboard to summarize key hospital performance indicators.
- Present insights through Pivot Tables, charts, and KPI summaries.

## 🛠️ Tools & Technologies
- **Microsoft Excel**
- **Power Query** – Data cleaning and transformation
- **Pivot Tables** – Data summarization and analysis
- **Pivot Charts** – Visual analysis
- **Excel Dashboard** – KPI reporting and interactive filtering

## 🔄 Project Workflow

### 1. Data Cleaning
- Handled missing and invalid values.
- Standardized inconsistent categories and text formats.
- Validated billing amounts and identified unusual values.
- Prepared structured data for analysis.

### 2. Data Analysis
- Summarized hospital revenue and billing information.
- Analyzed patient demographics and ratings.
- Used Pivot Tables to group and compare relevant metrics.
- Identified trends and patterns in the available data.

### 3. Dashboard Development
- Designed a dashboard with KPI summaries and charts.
- Presented important revenue and patient-related metrics.
- Used slicers and interactive filters to explore the data.
- Organized the visuals to make the results easy to understand.

## 📊 Key Deliverables
- Cleaned hospital dataset
- Pivot Table summaries
- Charts for patient and revenue analysis
- Interactive Excel dashboard

## 💡 Key Learnings
- Data cleaning and transformation using Power Query
- Data summarization using Pivot Tables
- Building charts and interactive Excel dashboards
- Translating raw healthcare data into actionable insights

## 🚀 Conclusion
This project demonstrates practical Excel skills in data preparation, analysis, visualization, and dashboard development within the healthcare domain.
